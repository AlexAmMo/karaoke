# Karaoke classic HUD

These are original geometric assets for Karaoke's adaptation of the classic PS3 karaoke presentation. They contain no extracted Sony images, logos, typefaces or UI artwork. Generated by `scripts/create_theme_assets.py` using only Python's standard library; licensed under this repository's GPL-3.0-only license.

`prepare_engine_theme.py` builds the Karaoke theme and Classic skin from the pinned Deluxe Modern theme, preserving its GPL notices and auxiliary resource mappings. Only the singing HUD is restyled: slim capsule guides, sung notes, the two-tone lyric band, quiet scores, and an original pause veil. Fonts remain the bundled Noto Sans family and its existing OFL license. The original 4:3 game coordinate system is preserved.
