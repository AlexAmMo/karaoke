# Referencias visuales de SingStar clásico para PS3

Investigación: 14 de noviembre de 2026. Referencia confirmada por el usuario: **SingStar clásico de PS3**, anterior al rediseño de 2014. Esta nota documenta evidencias; no modifica la aplicación ni DESIGN.md.

## Cinco fuentes principales

### 1. Nigal Raymond: diseñador del original

[Portfolio SingStar PS3](https://www.nigalraymond.com/singstar-ps3). Acredita diseño de interfaz y motion graphics a Nigal Raymond, dirección creativa a Alex Townsend y un periodo de trabajo de 2005–2007. Las imágenes se atribuyen a Sony Interactive Entertainment. Es una fuente primaria de autor, aunque las piezas son composiciones de prensa, no grabaciones de una sesión de juego. Las fechas del proyecto no demuestran que todas las capturas sean de una única versión de lanzamiento: una muestra incluye «Best of 2008».

Capturas inspeccionadas visualmente en navegador:

- [Identidad y fondo de escenario](https://images.squarespace-cdn.com/content/v1/58a4c0ee9f74561a7d78a91f/1509270975875-N2IW7C3ZRP4F6XNBBX0E/SingStar-Press-Image_001.jpg?format=1500w): rojo carmesí, horizonte, suelo reflectante, trazos de luz y siluetas de cantantes.
- [Catálogo SingStore](https://images.squarespace-cdn.com/content/v1/58a4c0ee9f74561a7d78a91f/1509270976488-TN8JL4LCR5QI6QC0KDV3/SingStar-Press-Image_002.jpg?format=1500w): portada seleccionada ampliada a la izquierda, retícula compacta, índice lateral y pie de controles.
- [Gameplay](https://images.squarespace-cdn.com/content/v1/58a4c0ee9f74561a7d78a91f/1509270978449-VV8B9SZCLCI062ZELYGX/SingStar-Press-Image_004.jpg?format=1500w): videoclip a pantalla completa, notas cápsula azul/cian, líneas de tono discretas, puntuación a la derecha y dos líneas de letra en una banda blanca/gris inferior.

### 2. Ffred S: capturas de interfaz PS3 a 1280 × 720

[Portfolio Singstar](https://www.ffred.com/work/singstar). Publicado en 2017; el texto identifica el producto como PS3. No fechar las pantallas como 2007: el carrusel muestra «Paradise» de Coldplay. Tampoco asumir que todo portfolio equivale exactamente a una compilación comercial identificada.

Capturas inspeccionadas visualmente en navegador:

- [Song Selection](https://images.squarespace-cdn.com/content/v1/58be8df6c534a57a90f9cf46/1489345785539-UNL84VAMJN5QU9XAKQD7/SS_Carousel_SingStore%2BD-01.png): carrusel horizontal de portadas; foco central ampliado, título/artista en bloque fucsia inferior, reflejo vertical; índice alfabético a la derecha, blanco para la letra activa; contador arriba; pie claro con Navigate, Select y Back. Fondo burdeos casi negro con luz roja superior/inferior. Un pequeño ecualizador blanco acompaña la selección.
- [Main Menu](https://images.squarespace-cdn.com/content/v1/58be8df6c534a57a90f9cf46/1489345745847-FAENPFA7OHLB01KHJWHA/FPN_Main_Menu-02.png): título grande de trazo fino blanco; banner superior; acción Play SingStar de mayor tamaño que Media Gallery y Options; pie persistente.

Hay una esquina inferior derecha redondeada en los bloques principales, no una repetición uniforme de tarjetas redondeadas por toda la pantalla.

### 3. PlayStation: navegación confirmada como carrusel

[SingStar Global Patch Adds Voice Control, Trophies and More — 20 de abril de 2009](https://blog.playstation.com/?p=9243). La product marketing manager confirma que el menú de voz permite recorrer el **song carousel** y seleccionar canciones. También documenta rediseños de SingStore y MySingStarOnline. Esto respalda el modelo de navegación, no los tiempos de animación ni una fuente tipográfica concreta. Contiene referencia a un tráiler de SingStar Queen; **no se ha reproducido ni analizado ese vídeo en esta investigación**.

### 4. PlayStation: PS3 tuvo revisiones visuales internas

[This Week On The SingStore — actualización de 6 de octubre de 2010](https://blog.playstation.com/archive/2010/10/04/this-week-on-the-singstore-06-october-2010/comment-page-2/). Documenta cambios en Play SingStar, nombres de modos, configuración de jugadores, pantallas de puntuación e iconos. Por tanto, «PS3 clásico» no identifica una única versión exacta. Esta fuente sirve especialmente para evitar presentar una reconstrucción de resultados como copia verificada de 2007.

### 5. PlayStation: límite con el rediseño de 2014

[SingStar on PS4, PS3: Out Soon, New Features Detailed — 15 de octubre de 2014](https://blog.playstation.com/2014/10/15/singstar-on-ps4-ps3-out-soon-new-features-detailed/). Sony anuncia una renovación de interfaz para ambas consolas, junto con la app de micrófono y cola desde el móvil. **Que una captura diga PS3 no basta para clasificarla como clásica**: Ultimate Party y el software renovado de 2014 pertenecen a otra etapa. No se toma su estética como referencia principal.

## Lectura práctica para Karaoke

Estas son **decisiones propuestas para nuestra adaptación**, no especificaciones oficiales extraídas del juego:

| Área | Aplicación propuesta |
| --- | --- |
| Paleta | Base burdeos/negro rojizo; luz carmesí; selección rosa/fucsia; texto blanco; pequeños acentos cian en controles. Son familias observadas, no colores hexadecimales certificados. |
| Jerarquía | Una elección dominante, vecinos secundarios, encabezado ligero y controles discretos. Evitar que estadísticas, configuración y catálogo compitan con la canción elegida. |
| Tipografía | Buscar una sans ligera y abierta para títulos, con lectura cómoda a distancia; no atribuir una familia exacta a Sony sin evidencia. Para texto funcional, priorizar contraste y tamaño frente al parecido literal. |
| Selección | Tratar el catálogo como un escenario horizontal con foco inequívoco. Separar explorar, confirmar y actuar; mostrar artista, canción y estado de disponibilidad junto a la selección. |
| Navegación | Foco visible y recorrido predecible con teclado/mando; confirmar y volver en ubicaciones estables. Mantener acceso directo a búsqueda para bibliotecas grandes. |
| Cola | El panel derecho colapsable es un requisito propio confirmado por el usuario, no una característica histórica demostrada de SingStar. Al cerrarlo, recuperar espacio para la canción y mantener un acceso compacto que muestre el número de temas en cola. |
| Gameplay | Dar todo el protagonismo al vídeo y a las letras; dejar fuera los controles administrativos durante la interpretación. Las notas y la puntuación solo corresponden si nuestra aplicación implementa esas funciones. |
| Resultados | El vídeo aporta una referencia visual; una adaptación puede conservar la jerarquía rango, puntuación y siguiente acción. No atribuir esa versión a un año exacto. |
| Movimiento | Aplicar expansión del foco y desplazamiento del carrusel observados en vídeo, eligiendo tiempos accesibles propios. Las curvas y duraciones siguen sin estar medidas. |

## Inspección y límites

Abrir los enlaces directos de las cinco capturas anteriores para comparar estructura y colores; la captura del portfolio ff es la más útil para selección de canciones. La pieza de gameplay de Nigal Raymond es la referencia más fuerte para la separación entre navegación y canto. La composición de prensa incluye televisor y periféricos: analizar el área de pantalla, no convertir ese marco en parte del diseño.

Se han observado imágenes estáticas y los tramos de vídeo indicados mediante el navegador. No se han descargado medios remotos, medido colores con cuentagotas, identificado fuentes ni verificado el audio de navegación. Los resultados automáticos de búsqueda de imágenes sirvieron para descubrir fuentes, no como prueba visual por sí solos. Para una reproducción temporal exacta aún falta medir una grabación de una compilación identificada; tampoco se verificó una transición continua entre selección y gameplay.
